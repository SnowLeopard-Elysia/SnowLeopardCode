# Snow Leopard Code 官网双标题区居中重排设计

## 背景

官网目前有两处标题区出现明显的视觉失衡：

- “把复杂任务，变成清楚可控的完成过程”被限制在左侧较窄区域，标题换行生硬，右侧留下大面积无意义空白。
- “只说一句话，也能交付完整结果”采用左右分栏，标题与说明距离过远，说明文字像悬浮在页面右侧，与下方案例缺少连续关系。

本轮只调整这两个标题区的排版，不修改文案、功能卡、案例内容、图片、配色或交互。

## 设计目标

1. 两处标题区使用同一套视觉结构，形成稳定的页面节奏。
2. 标签、标题、说明之间建立清楚的阅读顺序。
3. 消除左右视觉失衡和无意义的大面积空白。
4. 保持 Snow Leopard Code 官网现有克制、轻盈的视觉语言。
5. 桌面与移动端均保持清晰、自然的中文换行。

## 最终方案

采用“纯净纵向居中式”。每个标题区从上到下依次为：

1. 小型玫红标签。
2. 主标题。
3. 说明文字。

三个元素整体居中，不增加卡片、背景块、装饰线或额外图标。

## 版式规格

### 容器

- 标题组水平居中。
- 标题组最大宽度约 860px。
- 标题组与下方内容保持约 52px 的间距。
- 两个标题区共享相同的布局规则，避免一处居中、一处分栏。

### 标签

- 保留现有玫红色和字重。
- 居中显示。
- 标签与主标题间距约 18px。

### 主标题

- 桌面端最大宽度约 820px。
- 使用现有字号体系，桌面端约 48–52px，移动端约 29–40px。
- 行高约 1.18–1.22，避免两行文字挤压。
- 不强制插入换行，由容器宽度决定自然换行。
- 中文字距维持轻微收紧，但不出现拥挤感。

### 说明文字

- 最大宽度约 680px。
- 紧跟主标题，间距约 20px。
- 居中显示，行高约 1.8。
- 继续使用现有次要文字颜色，并确保正文对比度不低于 WCAG AA 4.5:1。

## 响应式行为

- 1000px 以下保持纵向居中，不再切换为左右分栏。
- 720px 以下缩小标题字号和标题组外边距。
- 移动端说明文字允许自然换行，左右保留至少 20px 的安全留白。
- 不改变下方功能卡和案例卡的现有响应式结构。

## 实现范围

主要修改：

- `src/styles/global.css` 中的 `.section-heading`、`.demo-heading` 及其标题和说明规则。
- 如有必要，为两个标题区增加共享类名，但不改变内容结构或数据结构。

不修改：

- 功能卡片布局。
- 案例卡片与图片。
- 页面文案。
- 下载、导航、模型、隐私等其他区域。

## 验收标准

1. 两个标题区均为标签、标题、说明的纵向居中结构。
2. 第二个标题区不存在左右分栏或右侧悬浮说明。
3. 桌面端标题视觉宽度均衡，不出现截图中的突兀窄列换行。
4. 1366px、1920px、720px 以下宽度均无溢出或重叠。
5. Astro 检查与生产构建通过。
6. GitHub Pages 部署后样式保持内联，不出现裸 HTML 页面。
